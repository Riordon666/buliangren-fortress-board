# 饰品强化与分解数据

核对日期：2026-09-12。页面 `/accessories`；结构化数据 `lib/accessory-enhancement-data.json`；范围求和 `lib/accessory-enhancement.ts`。

## 数值口径

- 全部以传说品质为范围，不把精良/优秀品质混入。赤魂耳环独立分支，普通部位默认表保留 45 符，耳环 +20 为 61 符。
- `level: N` 的 `upgrade` 是 `+(N-1) → +N` 强化一次的尘、星，以及勾选保护符时的用量。区间合计排除起点、包含终点。不使用保护符时失败/降级/重试会产生额外消耗，未估算其概率成本。
- `dismantle` 是所列来源该等级的返还数字。官方工具截图、玩家实录、原作者模拟器的口径可能有区别；尤其后期作者表未确认是否含 +0 本体基础返还，不宣称全部为游戏精确最终结算。
- `null` 表示缺少可靠值，不能当成 0。逐材料传播空缺；某项区间有任何一格未知，该项合计为未知。0 仅用于已确认不需要/不返还的材料；+0 没有升级动作，UI显示横杠。
- 表仅覆盖强化，+35 后的精炼1–5不作为+36～+40。
- 这是带核对日期的静态参考资料，未接游戏官方实时接口。
